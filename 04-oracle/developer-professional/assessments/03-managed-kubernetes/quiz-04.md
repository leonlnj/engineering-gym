## Resolved

- **Q1/Q6** (out-of-place tier availability + drain responsibility): added to §5.2 — node cycling's Enhanced-only gate is specific to *in-place* upgrades; an out-of-place upgrade drains onto a new pool instead and isn't gated by tier at all, confirmed against Oracle's separate in-place/out-of-place upgrade docs.
- **Q2** (cost break-even point): left **open, deliberately not guessed** — computing a genuine break-even utilization threshold needs a managed-node instance rate the lesson doesn't otherwise cite, and inventing one would violate the track's verified-figures policy. Ranked lowest of the five for this reason.
- **Q3** (sidecar logging + `emptyDir` interaction): added to §3.3 — the sidecar and app container share the single allowed `emptyDir`, confirmed against Oracle's virtual-node application-logging docs; reframed as the mechanism the one-`emptyDir` allowance exists to support, not a conflict with it.
- **Q4** (endpoint flag failure mode): added to §4.1 — `--endpoint-public-ip-enabled true` against a private subnet fails provisioning outright rather than silently downgrading, confirmed against the OCI CLI command reference.
- **Q7** (kubeconfig credential mechanism): added to §4.2 — `create-kubeconfig` takes `--auth=instance_principal` (or `resource_principal`) to mint tokens from a non-personal identity, confirmed against the OCI CLI command reference.
