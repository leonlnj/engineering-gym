## Questions

1. A monorepo holds three services. Pushes touching only `services/orders/` must rebuild only the orders pipeline. How? _(triggers + monorepo · production-reasoning)_
2. Design "build once, promote through dev → stage → prod with a gate before prod" using DevOps primitives. Which twelve-factor factors does the design express? _(promotion design · production-reasoning)_
3. Your home region has an outage. Can your DevOps pipelines deploy the last-built image to a cluster in another region? What does the answer depend on? _(regionality/DR · production-reasoning)_
4. The GitHub personal access token behind your external connection must be rotated quarterly. What is the rotation procedure's shape, given how the connection stores it? _(connection secrets · production-reasoning)_
5. Builds take 9 minutes, 6 of which are `docker pull` + dependency downloads on the fresh runner. What are your mitigation options? _(build performance · production-reasoning)_
6. Compliance wants a nightly rebuild of `main` even with no commits. Do DevOps triggers support this, and if not, what is the idiomatic wiring? _(scheduled builds · production-reasoning)_
7. Only production deployments need human sign-off; dev and stage must flow through untouched. Where does the approval live? _(pipeline topology · production-reasoning)_
8. During an incident you know only the failing pod's image tag. Walk the chain back to the code change and its pipeline events. _(traceability · production-reasoning)_
9. A blue-green release includes a database schema change. Why is "instant rollback" no longer instant, and what migration discipline restores it? _(blue-green + schema · production-reasoning)_
10. In `iad.ocir.io/acme/orders-service:9f3c2ab`, what are the three path components, and which one is tenancy-wide? _(OCIR anatomy · exam-ready)_
