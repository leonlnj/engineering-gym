   A. `env.variables`  B. `vaultVariables` referencing a secret OCID  C. `exportedVariables`  D. hardcoded in the step _(secrets · exam-ready)_

   A. Wrong region key  B. Missing dynamic-group policy  C. Image too large  D. OCIR outage _(IAM debugging · exam-ready)_

   A. OKE  B. Compute instance group  C. Functions  D. All support it _(strategy gating · exam-ready)_
6. A trigger on an OCI code repository can fire on which events?
   A. Push only  B. Push and PR-created  C. All PR events  D. Push and tag _(trigger gating · exam-ready)_
7. Same app, different database URL per environment, one codebase — which twelve-factor factor?
   A. I Codebase  B. III Config  C. IV Backing services  D. X Parity _(12-factor · exam-ready)_
8. Blue-green on OKE requires all of the following EXCEPT:
   A. Two pre-created namespaces  B. Manifests that omit the namespace  C. An NGINX ingress controller  D. A service mesh _(blue-green prerequisites · exam-ready)_
9. A value computed during a build (an image tag) reaches the deployment pipeline via:
   A. `outputArtifacts`  B. `exportedVariables`  C. `inputArtifacts`  D. a Vault secret _(build spec mechanics · exam-ready)_
10. An instance-group deployment fails on a fleet of Ubuntu VMs with the Run Command plugin enabled. Why?
    A. Plugin unsupported  B. Ubuntu is not a supported OS  C. Missing NGINX  D. No namespace _(instance-group gating · exam-ready)_
11. An engineer rejects a deployment pipeline's approval stage. What happens to the running deployment?
    A. It pauses indefinitely  B. It continues with a warning  C. The stage fails and the run stops  D. It rolls back the previous release _(approval semantics · exam-ready)_
12. Which stage type creates a fixed bake period after a canary traffic shift?
